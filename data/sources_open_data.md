# Sources open data optionnelles - Assurance

Le projet peut etre realise entierement avec les donnees synthetiques fournies.

- CASdatasets / freMTPL: https://dutangc.github.io/CASdatasets/reference/freMTPL.html  
  Donnees actuarielles auto France: frequence et severite de sinistres.

- OpenML freMTPL2freq: https://www.openml.org/d/43593  
  Alternative pratique pour recuperer des donnees tabulaires.

- Mendeley insurance_claims: https://data.mendeley.com/datasets/992mh7dk9y/2  
  Jeu oriente detection de fraude. Verifier licence et anonymisation avant usage en formation.
